Client Setup

One-time (re-runnable) seed for the Client → Work Order hierarchy — loads the real client roster and numbered work orders, then reconciles anything already in the system.

1 · Client roster

The client-level revenue forecast workbook (Customer / Jan–Dec / Total / PM).

2 · Work orders

The "by customer-project" workbook (Customer Name / Job Name / monthly $).

3 · Commit seed

Idempotent — matches existing clients by name and existing work orders by client + name, so re-running with an updated workbook only adds what's new. Any client left with no work order (lump-sum clients — no job numbers) gets an auto "General" work order.

4 · Add a lump-sum client by hand

For clients billed as a flat monthly total with no numbered jobs (not covered by the two workbooks above) — creates the client and its "General" work order directly.

5 · Reconcile existing pipeline projects

Live projects that predate this restructure and only carry the old free-text client field. Best-guess matches are pre-selected — review before applying.

6 · Merge duplicate clients

Reassigns every work order from one client to another and retires the duplicate (e.g. two spellings of the same company).
